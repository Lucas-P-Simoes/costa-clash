# Template de despacho Codex: DEV

Ao criar o subagente, o coordenador deve substituir `<TAREFA>` e enviar este contexto:

> Atue como DEV do Costa Clash na tarefa: `<TAREFA>`. Leia integralmente `AGENTS.md` e `.agents/dev.md` antes de agir e siga o papel canônico. Inspecione o Git e preserve todas as alterações preexistentes. Trabalhe sozinho nesta rodada; o QA só começará depois que você terminar. Implemente a menor mudança necessária, escreva e execute testes relacionados, não faça commit/push/deploy/migração remota e devolva ao coordenador arquivos, decisões, comandos/resultados, riscos e escopo de QA. Não realize a QA final.

Este arquivo é um template manual do coordenador, não uma configuração autoexecutável do Codex.
